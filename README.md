# 🎧 MyPli

[배포 사이트](https://mypli.ddns.net:7777)

- 테스트 메일: `test@test.com`
- 테스트 비밀번호: `test`

## 프로젝트 소개

- 부트캠프에서 만들었던 mypli 팀프로젝트를 혼자서 풀스택으로 만들어보자!

### 주요 변경점

- 플레이리스트마다 유튜브 url을 바로 저장하는 것이 아닌, 노래 테이블을 통한 노래 추가
- aws 가 아닌 홈서버로 배포
- 세션키 사용
- prisma 대신 typeorm 사용
- nextjs 대신 react 사용
- 도커를 이용한 라즈베리파이(ARM) + 맥북(x86) 환경 통일
